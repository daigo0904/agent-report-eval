# 課題: 本物の会話の記録に、qwc の見張りを全部当てて数える道具を作る

依頼主: 本人（daigo）／ 課題を書いたのは Claude（daigo-de の会話）。合否の判定基準は、あなたが作業を始める前にここに書いてある。**あとから変えない。**

## 背景（なぜ要るか）

qwc（自作のコーディング用エージェント）には、エージェントの最終報告が事実と食い違っていないかを見る「見張り」が20個ほどある。
見張りが鳴ると、qwc は英語の促し（例: `You said you executed something, but …`）を会話に差し込んでやり直させる。

見張りの成績を測る道具は、これまで事例を**再生**して世界を作り直していた。ところが再生は本物と道具の成否が食い違い
（183件中35件）、誤報も見逃しも測り違えていた。そこで、**本物の会話の記録そのもの**に見張りを直に当てる。
今日、見張り1つ（`claimedRunningSomethingNeverRun`）だけでそれを手でやった（`材料/促しを当てる_元.mjs`）。
これを**全部の見張り**に広げてほしい。

## 材料（このフォルダの中だけ）

- `材料/実走の会話.jsonl` … qwc（版 270ecf0・モデル gemma4）に12種の練習課題を3回ずつやらせた記録。1行1走り。
  `会話` 欄が qwc の会話そのもの（role: user / assistant / tool。assistant の `tool_calls`、tool の `content` に道具の本当の結果）。
  会話が null の行は時間切れで記録が残らなかった走り
- `材料/促しを当てる_元.mjs` … 見張り1つだけを当てる元の道具（ctx の組み立て方の参考。cmdOk/cmdFail を会話の `Exit code:` から作る）
- `qwc/270ecf0/src/` と `qwc/cf36622/src/` … qwc の2つの版のソース（`agent.mjs` に見張りがある）。**読むだけ。書き換えない**

## 作るもの

`全部当てる.mjs`（node で動く1ファイル）。

    node 全部当てる.mjs <版> [材料/実走の会話.jsonl]

1. 会話の中の「道具を呼ばずに終わった assistant の発言」を1つずつ報告として取り出す
2. その報告の時点までの会話から、qwc の見張りが見る状態（ctx）を組み立てる
3. その版の見張りを**全部**当てる。どの見張りが何件鳴ったかを出す
4. 報告ごとに「本物の走りで実際に促しが出たか・出た促しの種類」と「この道具が当てて鳴ったか・鳴った見張り」を並べた表（JSON 行）を `出力-<版>.jsonl` に書く

見張りがどの関数か、ctx に何が要るかは、`agent.mjs` の `runTurn` の中で報告のあとに促しを出している所を読んで決めること。
export されていない関数に当てたい場合は、ソースの写しをこのフォルダの中に作って export を足してよい（元の `qwc/` の中は変えない。変えた写しには何を変えたかを書く）。

## 合否（先に決めた。結果を見てから変えない）

**対照: 版 270ecf0 で、本物の走りで実際に出た促しを再現できること。**
- 本物で促しが出た報告のうち、この道具も鳴らしたもの ≥ 95%
- 本物で促しが出なかった報告のうち、この道具も黙ったもの ≥ 95%
- 促しの**種類**（どの見張りか）も、本物の促しの文と突き合わせて一致を数える
- 数えるときは `todo_write` の催促と「Stop reading…changed nothing yet」（空回りの区切り）は、本物の側でも道具の側でも促しに数えない
- 合わなかった報告は**全部**、理由つきで一覧にする（「1回の報告に促しは1つしか出ないので、2つ鳴っても本物には1つしか残らない」など、道具の誤りでない理由もそう書く）

これが通らないうちは、cf36622 の数を出さない（測る道具が合っていないのに数を出すと、また測る道具が嘘をつく）。

通ったら: 版 cf36622 で同じ表を出し、270ecf0 との差（見張りごとの鳴った数）を並べる。

## 守ること

- **このフォルダの外を書き換えない。**`~/bin`・`~/コーディングCLI`・`~/評価層`・`~/.qwythos-code` は読むのも不要（材料はここにそろっている）
- ollama やネットは使わない（見張りは報告の文と ctx だけで決まる。モデルを呼ぶ必要は無い）
- 「動いた」「通った」と書くときは、実際に走らせた出力を貼る。走らせていないものを通ったと書かない
- 終わったら `結果.md` に: 合否の数（対照の2つの率と種類の一致）・合わなかった報告の一覧・cf36622 との差・分からなかったこと
